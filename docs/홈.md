# AiMate 개발 위키

AiMate는 Discord와 터미널에서 캐릭터와 대화하는 서비스다. 한 프로세스에서 여러 캐릭터를 실행하며, 각 캐릭터는 자기 계정·관찰 기록·대화 상태를 가진다. 짧은 메시지를 나눠 보내고, 대화 중 새 입력이 오면 답변을 다시 준비한다.

Node.js ESM, Vercel AI SDK, discord.js, Prisma와 SQLite를 사용한다.

## 코드에서 출발한다면

| 파일 | 읽을 이유 |
| --- | --- |
| [src/main.js](../src/main.js) | 설정을 읽고 실행할 캐릭터와 연결을 선택한다. |
| [src/core/container.js](../src/core/container.js) | 캐릭터 하나에 필요한 객체와 의존성을 조립한다. |
| [src/messages/MessageHandler.js](../src/messages/MessageHandler.js) | 수신한 발언·수정·삭제를 저장하고 응답을 예약한다. |
| [src/chat/ChatFlow.js](../src/chat/ChatFlow.js) | 입력 준비부터 모델 호출·전송·완료까지 이어준다. |

현재 구현은 Discord·CLI 대화, 다중 캐릭터, 수정·삭제 관찰, 답장·리액션, 이미지 생성, 재생성, 정책과 로그를 포함한다. 이미지 도구는 첨부를 지원하는 연결에서 제공한다. 장기 기억의 자동 추출·주입과 Instagram 연결은 구현되어 있지 않다.

옵시디언에서는 `docs/`를 보관함으로 열면 된다. 문서 링크는 상대 경로이며 소스 링크는 보관함 밖의 실제 파일을 가리킨다. 소스는 저장소를 연 코드 편집기에서도 찾을 수 있다.

설명은 현재 코드와 [대화 통합 테스트](../test/integration/ChatPipeline.integration.test.js)를 기준으로 한다. 기능을 바꾸면 해당 주제의 문서도 갱신한다.
