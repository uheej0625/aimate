# AiMate 개발 위키

AiMate는 Discord와 CLI에서 짧은 메시지를 여러 번 주고받는 AI 대화 봇이다. 두 플랫폼은 같은 대화 파이프라인을 사용한다. 이 위키는 현재 구현의 동작과 수정 지점을 설명한다.

분석 기준일은 2026-10-05다. 소스·설정 로더·Prisma 스키마·테스트를 기준으로 작성했으며, 문서의 설명과 실제 코드가 다르면 코드를 확인하고 문서를 갱신한다. 구현 경로는 프로젝트 루트 기준이다. 보관함 밖의 소스는 코드 편집기에서 해당 경로로 찾는다.

## 현재 진행상황

- 템플릿과 이미지의 시각·런타임 컨텍스트를 `src/utils/templateContext.js`로 통합했다. 현재 시각은 초와 실제 오프셋을 포함한 ISO 8601로 전달한다.
- 캐릭터 `config.json`의 필수 IANA 시간대로 채팅 관찰 시각·현재 시각·나이·학년 계산을 통일했다. 시작 시 설정 누락과 오류를 검증한다.
- 기본 설정은 `character: "haneul"`, 채팅 프롬프트 `default`, 이미지 프롬프트 `ultimate`를 사용한다. 캐릭터와 프롬프트 원문은 앱 저장소의 Git 제외 대상으로 유지한다.
- 고정 사례의 프롬프트 비교와 Codex 대화 품질 점검 도구가 연결되어 있다. 자동 검증과 실제 모델의 대화 품질 검토는 구분한다.
- 채널별 고정 메시지 번호와 Discord reply/react 도구를 구현했다. [메시지 번호와 답장·리액션](대화/메시지%20번호와%20답장·리액션.md)에서 현재 계약을 확인한다.
- AI는 빈 messages로 응답을 마칠 수 있다. reply/react만 실행하거나 완전히 침묵해도 정상 완료하고 입력 처리 위치를 전진시킨다. 실제 전송·리액션이 없으면 sentAt은 비워 둔다. [생성과 전송 및 재생성](대화/생성과%20전송%20및%20재생성.md)에서 완료 계약을 확인한다.
- `summary`·`fact`·`episode`의 컨텍스트 주입은 아직 구현되지 않았다.
- [로그](운영/로그.md)는 채널·turn·생성 ID로 대화부터 모델·도구·전송까지 연결한다. 기본 info는 생애주기와 결과를, debug는 건너뜀 사유·버퍼·단계별 시간·전송 상세를 기록한다.
- [메시지 분할](대화/메시지%20분할.md)로 긴 응답을 전송 제한에 맞추고 원본 messages와 실제 전달된 Message를 구분해 저장한다. [Humanize](대화/Humanize.md)는 타이핑 표시와 지연을 담당하며, 꺼도 길이 분할은 유지한다.

## 설계 제안·아이디어

아래 두 문서는 기존 내용을 그대로 보존한 기록이다. 현재 기능 설명과 구분해서 읽는다. 다른 과거 문서는 정리 과정에서 삭제했다.

- [channelMessageNo와 reply/react 도구 설계](v0.2.0/channelMessageNo와%20reply-react%20도구.md): 원문을 보존한 **설계 초안**. 현재 구현 계약은 [메시지 번호와 답장·리액션](대화/메시지%20번호와%20답장·리액션.md)이며 기존 데이터 적용 등 초안의 모든 항목을 구현한 것은 아니다.
- [JEV 응답 게이트 아이디어](archive/jev-response-gate-idea.md): 버퍼 교체 **아이디어**. 현재 런타임은 debounce 방식이며, 제안 문서의 외부 API·SDK 조건은 실제 구현 전에 다시 검증해야 한다.

channelMessageNo 초안 말미의 기존 설계·Prisma 링크 두 개는 과거 경로여서 열리지 않는다. 원문 보존을 위해 그대로 두었다. 현재 설명은 [메시지와 관찰 사건](대화/메시지와%20관찰%20사건.md)과 [데이터 모델](데이터/데이터%20모델.md)에서 확인하고, 스키마는 프로젝트 루트의 `prisma/schema.prisma`를 연다.

## 문서 갱신 원칙

기능·계약·설정 변경 시 관련 문서를 함께 갱신한다. 주요 문서에는 구현 경로와 검증 근거를 남기고, 계획을 구현 완료로 설명하지 않는다. 비공개 프롬프트·캐릭터 원문이나 인증 값을 복사하지 않는다.

근거: `src/core/container.js`, `prisma/schema.prisma`, `test/integration/ChatPipeline.integration.test.js`.
