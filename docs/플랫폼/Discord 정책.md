# Discord 정책

`/정책 설정 유형:대화`로 서버·카테고리·채널의 대화 허용 여부를 바꾼다. `/정책 상태 유형:대화`는 적용 상태와 근거, 다음 임시 설정 만료와 만료 후 상태를 보여 준다. 두 명령은 서버에서만 사용할 수 있고 서버 관리 권한이 필요하다. 결과는 실행자에게만 표시한다.

## 사용법

```text
/정책 설정 유형:대화 상태:허용 범위:서버
/정책 설정 유형:대화 상태:거부 범위:카테고리 대상:업무 기간:3시간
/정책 설정 유형:대화 상태:허용 범위:채널 대상:#잡담 기간:1시간
/정책 설정 유형:대화 상태:상속 범위:채널 대상:#잡담
/정책 상태 유형:대화
/정책 상태 유형:대화 범위:서버
```

| 옵션 | 동작 |
| --- | --- |
| 유형 | 필수 항목. 현재 지원하는 유형은 대화(conversation) |
| 상태 | 설정 명령의 필수 항목. 허용·거부·상속 |
| 범위 | 서버·카테고리·채널. 생략하면 채널 |
| 대상 | 생략하면 현재 위치. 카테고리 범위에서는 현재 채널의 카테고리, 채널 범위의 스레드에서는 부모 채널. 서버 범위에서는 지정하지 않음 |
| 기간 | 설정 명령의 선택 항목. 1·3·6·12시간·1일. 생략하면 무기한. 상속에는 지정할 수 없음 |

채널 범위는 텍스트·공지·포럼·미디어 채널을 지원한다. 스레드·포럼 게시글은 부모 채널 설정을 그대로 따른다. 스레드만의 개별 설정은 없다. 카테고리가 없는 채널에서 카테고리 범위를 쓰려면 대상을 지정한다. 대상은 같은 서버에 있어야 한다.

채널을 직접 활성화할 때 봇의 채널 보기·메시지 보내기 권한을 확인한다. 포럼·미디어는 스레드에서 메시지 보내기 권한을 확인한다. 비활성화·상속에는 봇 전송 권한을 요구하지 않는다. 서버·카테고리 활성화는 각 하위 채널의 Discord 권한을 변경하거나 전송 성공을 보장하지 않는다.

정책 저장과 판정의 공통 계약은 [권한과 정책](../구조/권한과%20정책.md)에 있다. 채널 만들기·프로필 조회 등의 별도 유형은 아직 제공하지 않는다.

## 우선순위와 상속

적용 순서는 **채널 → 카테고리 → 서버 → 기본 비활성화**다. 각 범위에서 유효한 개별 설정이 있으면 그 값을 사용한다. 비활성화도 명시적인 설정이며 상속과 다르다.

예를 들어 서버가 활성화이고 업무 카테고리가 비활성화이면 업무 카테고리에서는 대화하지 않는다. 그 안의 특정 채널을 활성화하면 해당 채널과 그 스레드에서는 대화한다. 채널에 `상속`을 적용하면 그 채널의 기본·임시 설정을 모두 지우고 카테고리를 따른다.

서버를 비활성화해도 개별 활성화한 채널·카테고리는 유지된다. 서버 전체를 강제로 끄는 긴급 정지 기능은 제공하지 않는다. 새 채널도 첫 메시지부터 현재 서버·카테고리 설정을 따른다. 채널을 옮기면 현재 카테고리를 사용하고, 채널의 개별 설정은 유지한다.

로그 전용 채널과 그 스레드는 서버·카테고리 활성화 여부와 관계없이 대화에서 제외한다. 로그 전용 채널에 직접 활성화를 설정하면 오류로 안내한다. 로그 구독 해제 후에는 대화 설정을 다시 판정한다. 등록된 Channel 행의 존재는 Discord 활성화 근거가 아니다. DM은 활성화하지 않는다.

## 임시 설정

각 대상에는 기본 설정 하나와 임시 설정 하나를 저장한다. 기간을 지정하면 기본 설정을 유지한 채 임시 설정을 적용한다. 임시 설정을 다시 지정하면 기존 임시 설정과 만료 시각을 교체한다. 기간 없이 설정하면 기본 설정을 변경하고 임시 설정을 지운다.

만료 시 과거 상태를 복사하거나 반대 상태로 바꾸지 않는다. 해당 대상의 기본 설정이 있으면 사용하고, 없으면 **그 시점의 상위 설정**을 따른다. 기본 설정이 없는 대상에 임시 설정만 만들 수도 있다. 만료된 임시 값은 판정에서 무시하며 임시 값만 남은 행은 설정 목록에서 숨긴다. 별도 삭제 작업은 필요하지 않다.

`Policy`의 conversation 유형에 기본 effect(allow/deny)·temporaryEffect·만료 시각을 저장하므로 재시작 후에도 같은 시각에 만료된다. 수신·생성 시작·모델 호출 전·출력 수락·완료·메시지 조각 전송·도구 실행 직전에 현재 시각으로 판정한다. reply/react는 실제 외부 작업 직전에도 다시 검사한다. 활성 대화는 1초 주기로 재확인해 새 메시지가 없어도 만료·카테고리 이동·로그 채널 전환에 따른 중단을 반영한다. 타이머가 늦어져도 전송 직전 검사가 만료된 응답을 차단한다.

## 비활성화와 기록

비활성화하면 새 CREATE 메시지는 저장하거나 응답에 예약하지 않는다. 등록되지 않은 채널도 상위 활성화가 허용한 첫 CREATE를 저장하면서 자동 등록한다. 비활성화된 동안의 메시지를 활성화 시 다시 가져오거나 처리하지 않는다.

이미 저장된 메시지의 UPDATE·DELETE는 최신 상태에 반영하지만 관찰 사건이나 응답을 만들지 않는다. 저장되지 않은 UPDATE는 무시하며 부분 메시지 본문도 조회하지 않는다. 기존 Message·Event·Generation 기록은 지우지 않는다. 재생성 명령도 비활성화된 채널에서는 기존 출력을 삭제하기 전에 거절한다.

설정 변경으로 최종 상태가 비활성화된 대화는 버퍼를 비우고 현재 turn·주시 상태를 해제하며 진행 중인 모델 요청을 abort하고 Generation을 CANCELLED로 바꾼다. 개별 활성화가 유지되는 채널은 중단하지 않는다. 이미 시작한 외부 전송·리액션은 취소하거나 회수할 수 없으므로 확인된 결과는 기존 저장 정책대로 기록한다. 이후 조각과 도구 작업은 전송 전 재검사한다.

## 상태 조회

`/정책 상태 유형:대화`는 대상의 최종 상태, 적용된 범위와 기본·임시 설정 구분을 표시한다. 해당 상속 경로의 다음 만료 시각과 그 직후 예상 상태도 표시한다. 더 구체적인 설정이 남아 있으면 상위 임시 설정 만료 후에도 상태가 같을 수 있다. 조회 후 추가 설정 변경이 있으면 실제 만료 후 상태가 달라질 수 있다.

서버 범위는 서버 기본 상태와 개별 채널·카테고리 설정 개수를 보여 준다. 임베드는 최대 8개를 미리 보여 주고, 기본·임시 값·만료 시각·변경자·변경 시각을 담은 전체 설정 파일을 첨부한다. 서버 상태가 모든 채널의 상태가 같다는 의미는 아니다.
