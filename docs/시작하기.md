# 시작하기

목표는 CLI에서 첫 답변을 받은 뒤 같은 캐릭터를 Discord에 연결하는 것이다. 명령은 모두 저장소 루트에서 실행한다. 아래 `demo`는 예시 ID이므로 준비한 캐릭터 폴더 이름으로 바꾼다.

## 1. 패키지 설치

Node.js 24를 권장하며 이 환경에서 검증한다. AI SDK 7 업그레이드에 따라 `package.json`의 최소 버전은 22다. 다른 의존 패키지의 세부 요구 버전까지 충족하려면 Node.js 24를 사용한다.

PowerShell:

```powershell
node --version
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
```

## 2. 캐릭터와 프롬프트 준비

`content/characters/`와 `content/prompts/`는 Git에서 제외되어 있다. 저장소를 복제한 뒤 사용하는 콘텐츠를 별도로 준비해야 한다.

| 경로 | 용도 |
| --- | --- |
| `content/characters/demo/config.json` | 필수 동작 설정. 최소 내용은 `{ "timezone": "Asia/Seoul" }`. |
| `content/characters/demo/identity.md` | 캐릭터 정체성과 말투 템플릿. |
| `content/characters/demo/variables.json` | 이름·생일 등 템플릿 데이터. 생략하면 빈 객체로 처리한다. |
| `content/characters/demo/reference.png` | 셀피를 사용할 때 필요한 기준 이미지. |
| `content/prompts/<팩>/chat/sequence.js` | 채팅 프롬프트의 순서와 참조 파일 지정. |
| `content/prompts/<팩>/image/` | 이미지 도구용 `photo.md`, `selfie.md`, `screenshot.md`. |

로컬 콘텐츠가 없는 새 환경에서는 공개 테스트 자료로 CLI용 최소 구성을 만들 수 있다.

```powershell
New-Item -ItemType Directory -Force content/characters, content/prompts | Out-Null
Copy-Item -Recurse test/fixtures/character content/characters/demo
Copy-Item -Recurse test/fixtures/prompts/minimal content/prompts/minimal
```

이 경우 캐릭터 ID는 `demo`, `ai.chat.prompt`는 `minimal`로 설정한다. Decision 모드를 켤 경우 `ai.decision.prompt`도 `minimal`로 지정한다. 이 테스트 팩은 텍스트 채팅과 Decision 판단을 지원하며 이미지 템플릿은 별도로 준비한다. CLI 첫 실행에서도 아래의 image 설정 검증은 필요하다.

파일 형식은 [캐릭터 테스트 자료](../test/fixtures/character/)와 [채팅 프롬프트 테스트 자료](../test/fixtures/prompts/minimal/chat/)에서 확인한다. 실제 캐릭터·프롬프트 원문은 위키에 넣지 않는다. 작성 규칙은 [설정과 콘텐츠](설정과%20콘텐츠.md)에 있다.

## 3. CLI만 사용하는 설정 만들기

[config/default.yaml](../config/default.yaml)의 캐릭터 선택 부분을 준비한 콘텐츠에 맞춘다. 나머지 설정은 유지한다.

```yaml
character: demo
characters:
  - id: demo
    connections:
      cli: {}
    settings: {}
```

`ai.chat`과 `ai.image`의 `provider`, `model`, `prompt`를 확인하고, 선택한 provider의 인증 값을 `.env`에 채운다. `prompt`는 `content/prompts/` 아래 실제 팩 이름이다. 인증 변수는 [provider별 설정](설정과%20콘텐츠.md#모델과-인증)에서 확인한다.

시작 시 **chat과 image 설정을 모두 검증**한다. CLI는 이미지를 표시하지 않아도 image의 모델·팩 이름·인증 설정이 필요하다. API 키는 환경 변수에 두며 YAML에 넣지 않는다.

## 4. DB 초기화 후 첫 대화

```powershell
npm run db:init
npm run cli -- --character demo
```

`db:init`은 Prisma Client를 생성하고 현재 스키마를 SQLite에 적용한다. `.env.example`의 `DATABASE_URL="file:./dev.db"`는 `prisma/dev.db`를 가리킨다.

CLI가 열리면 메시지를 입력하고 `Enter`를 누른다. 기본 설정에서는 마지막 입력 후 5초를 기다린 뒤 실제 모델을 호출한다. 채널과 대화는 DB에 남아 다음 실행에서도 이어진다.

| 키 | 동작 |
| --- | --- |
| `Enter` | 전송 |
| `Shift+Enter` / `Alt+Enter` | 줄바꿈 |
| `Ctrl+N` | 새 채팅 |
| `Tab`, 방향키 | 채널 목록과 입력창 이동·채널 선택 |
| `PgUp` / `PgDn` | 대화 스크롤 |
| `Ctrl+Q` / `Ctrl+C` | 종료 |

선택한 캐릭터에 `discord: {}`도 있으면 **CLI 실행에서도 해당 Discord 계정에 로그인한다.** Discord 없이 확인하려면 위 예시처럼 `cli` 연결만 둔다. CLI는 실제 AI API를 사용한다. 외부 호출 없이 검증하려면 `npm test`를 사용한다.

## 5. Discord 연결

1. 같은 캐릭터의 `connections`에 `discord: {}`를 추가한다.
2. `.env`에 `AIMATE_DISCORD_DEMO_TOKEN`을 설정한다. ID의 영문자를 대문자로 바꾸고 하이픈은 밑줄로 바꾼 이름이다.
3. Discord 앱과 서버 권한을 준비한다. [client.js](../src/platforms/discord/client.js)는 Message Content·Guild Members·Guild Presences intent를 요청한다. 대화 채널에는 보기·전송·과거 메시지 읽기 권한이 필요하다. 이미지 전송에는 파일 첨부 권한도 필요하다.
4. 명령을 등록하고 실행한다.

```powershell
npm run deploy -- --character demo
npm start -- --character demo
```

`deploy`는 Discord에 명령을 등록한다. `DISCORD_GUILD_ID`를 설정하면 해당 서버에, 생략하면 전역에 등록한다.

로그인 뒤 서버 관리 권한이 있는 사용자가 대화할 채널에서 해당 봇의 명령을 실행한다.

```text
/정책 설정 유형:대화 상태:허용
/정책 상태 유형:대화
```

Discord 대화 정책은 기본 거부다. `범위:서버`를 추가하면 서버 전체의 기본값을 허용할 수 있다. 상속과 임시 허용은 [운영](운영.md#대화-정책)에서 설명한다.

## 실행 범위와 확인 지점

| 명령 | 실행 범위 |
| --- | --- |
| `npm start` / `npm run dev` | 목록에서 Discord 연결이 있는 모든 캐릭터. `dev`도 자동 재시작 없이 실행한다. |
| `npm start -- --character demo` | 지정한 캐릭터의 Discord 연결. |
| `npm run cli` | 최상위 `character`로 선택한 캐릭터. |
| `npm run cli -- --character demo` | 지정한 캐릭터의 CLI와 설정된 Discord 연결. |
| `npm run deploy` | 목록의 모든 Discord 계정에 명령 등록. |

기동 실패나 무응답은 [운영의 증상별 확인](운영.md#증상별-확인)으로 이동한다. 실행 코드는 [main.js](../src/main.js), 선택 로직은 [selection.js](../src/config/selection.js)와 [characters.js](../src/config/characters.js)에 있다. 기동·설정 검증은 [Host 테스트](../test/core/host.test.js), [설정 테스트](../test/config/selection.test.js), [AI 검증 테스트](../test/config/validateAiConfig.test.js)를 참고한다.
