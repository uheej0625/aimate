# 시작하기

## 위키 열기

옵시디언에서 **보관함으로 사용할 폴더 열기**를 선택하고 프로젝트의 `docs/`를 지정한다. `홈.md`부터 읽는다. 기존 폴더를 보관함으로 사용하는 방법은 [공식 안내](https://obsidian.md/help/vault)를 참고한다.

`docs/.obsidian/app.json`에는 일반 Markdown 링크, 상대 경로, 이름 변경 시 링크 자동 갱신을 설정했다. 설정의 ‘파일 및 링크’에서 확인할 수 있다. [공식 설정 안내](https://obsidian.md/help/settings)

코드와 실행 명령은 프로젝트 루트에서 사용한다. `src/`와 `prisma/`는 보관함 밖에 있으므로 문서에 적힌 경로를 코드 편집기에서 연다. 위키는 플러그인 없이 읽을 수 있다.

## 실행 준비

Node.js 요구 버전은 `package.json`의 `>=20.12.0`이다. 설치할 Node 버전은 의존 패키지의 engine 요구도 함께 확인한다. 다음은 PowerShell 예시다.

```powershell
npm install
Copy-Item .env.example .env
```

이미 `.env`가 있다면 복사하지 말고 필요한 항목을 확인한다. `DATABASE_URL="file:./dev.db"`는 Prisma 스키마 기준의 SQLite 파일을 사용한다.

`config/default.json`에서 `character`, `ai.chat`, `ai.image`를 확인한다. 선택한 provider의 인증 설정과 모델, 프롬프트 팩이 필요하다. 시작 시 chat과 image 설정을 모두 검증한다. 세부 조건은 [모델과 설정](AI/모델과%20설정.md)에 있다.

- 캐릭터: `content/characters/<character>/identity.md`, `variables.json`. 셀피에는 `reference.png`도 필요하다.
- 채팅 프롬프트: `content/prompts/<ai.chat.prompt>/chat/sequence.js`와 참조 Markdown 파일.
- 이미지 프롬프트: `content/prompts/<ai.image.prompt>/image/`의 도구별 템플릿.
- Discord 토큰: 캐릭터 ID를 대문자로 바꾸고 하이픈을 밑줄로 치환한 `AIMATE_DISCORD_<ID>_TOKEN`. `.env.example`의 예시 이름이 현재 캐릭터와 일치한다고 가정하지 않는다.

캐릭터·프롬프트 팩은 Git에서 제외되므로 저장소만 복제해도 준비된다는 보장은 없다. 필요한 로컬 팩을 먼저 준비한다.

```powershell
npm run db:init
npm run cli
```

`db:init`은 Prisma Client 생성과 `prisma db push`를 수행한다. CLI도 실제 AI 호출을 사용한다.

## Discord 실행

```powershell
npm run deploy
npm run dev
```

`deploy`는 Discord에 명령을 등록하는 외부 쓰기 작업이다. `DISCORD_GUILD_ID`가 있으면 해당 길드에, 없으면 전역에 등록한다. `/활성화`로 사용할 채널을 등록한다. Discord의 필수 intent와 권한은 [Discord](플랫폼/Discord.md)에서 확인한다.

## 각 단계에서 확인할 결과

| 단계 | 확인할 결과 | 실패하면 먼저 볼 것 |
| --- | --- | --- |
| 패키지 설치 | 의존 패키지와 Prisma 실행 도구 준비 | Node engine 조건, 설치 오류 |
| 환경 설정 | 선택한 chat·image provider와 토큰 이름 일치 | 현재 config와 환경 변수 이름 |
| 팩 준비 | sequence와 참조 템플릿, identity 존재 | Git 제외된 로컬 content 경로 |
| db:init | Prisma Client 생성과 SQLite 스키마 적용 | DATABASE_URL과 DB 파일 쓰기 권한 |
| CLI 실행 | 기존 채널 또는 새 채팅 화면 | 기동 검증과 채널 목록 조회 |
| Discord 실행 | 로그인·ready 뒤 명령과 이벤트 사용 가능 | 토큰, intent, 채널 등록·권한 |

명령은 프로젝트 루트에서 실행한다. 템플릿·캐릭터·이미지 경로는 process.cwd 기준으로 해석하는 부분이 있으므로 src나 docs로 이동해 진입점을 직접 실행하면 파일을 찾지 못할 수 있다.

## 빠른 시작과 개별 단계 실행의 차이

package.json의 npm run setup은 설치 → 설정 마법사 → DB 초기화 → Discord 명령 등록을 이어서 실행한다. scripts/setup.js는 .env 작성을 위한 대화형 입력을 받는다. 처음 구조를 확인할 때는 위의 개별 단계로 진행하면 어느 단계에서 문제가 발생했는지 구분하기 쉽다.

CLI는 Discord 토큰을 요구하지 않지만 chat·image 설정 검증과 실제 AI 인증은 필요하다. ‘Discord 없이 확인’과 ‘외부 API 없이 확인’은 다르다. 외부 호출 없이 동작을 검증할 때는 모델 대체 함수를 사용하는 테스트나 프롬프트 비교의 dry-run을 사용한다.

캐릭터·provider·프롬프트를 바꾼 뒤에는 새 프로세스에서 확인한다. 기존 watcher가 JSON을 읽었다는 로그만으로 활성 캐릭터·버퍼·팩이 모두 새 값으로 바뀌었다고 판단하지 않는다.
