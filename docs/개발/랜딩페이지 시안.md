# 랜딩페이지 시안

AiMate 소개 페이지는 봇과 분리된 형제 저장소 `landing-page/`에서 관리한다. 가입·결제·실제 봇 연결을 제공하지 않는 로컬 시안이다. 공개 배포나 봇 런타임 계약 변경을 뜻하지 않는다.

## 실행과 구성

`landing-page/`에서 `npm run dev`로 loopback 프리뷰를 실행한다. 기본 주소는 `http://127.0.0.1:4173`이다. 빌드나 봇 실행 없이 HTML·CSS·JavaScript로 동작한다. 자세한 재생 규칙과 실행 방법은 [랜딩페이지 README](../../../landing-page/README.md)에 있다.

밝은 배경과 녹색 강조색, 비대칭 구성, Discord 목업의 회전·확대를 유지한다. 소개 본문은 16px, 상세 설명은 14px, 보조 문구는 12px를 기준으로 표시한다. 한글 폰트는 라이선스와 함께 포함한 Pretendard 1.3.9를 사용한다. 목업 내부의 재현용 글자 크기는 컨테이너 비례 방식을 유지한다.

첫 화면에 직접 설치·운영하는 오픈소스 봇임을 안내한다. 외부 행동 유도 링크는 `GitHub에서 설치 방법 보기` 하나로 통일한다. 스토리는 데스크톱 390svh, 모바일 360svh이며 스크롤이 장면 진입을, 독립 시계가 대화 재생을 결정한다. 일시정지·다시 보기는 목업 변형과 분리된 최소 높이 48px 버튼으로 제공한다. 모션 감소 설정에서는 대화를 정적으로 펼치고 재생 제어를 숨긴다.

## 구현과 검증

- [index.html](../../../landing-page/index.html): 마크업, 한국어 기본 문구, 폰트 preload.
- [style.css](../../../landing-page/style.css): 공통 글자·간격 토큰, 명암 대비, 반응형 배치, 조작 상태.
- [locales/ko.js](../../../landing-page/locales/ko.js), [i18n.js](../../../landing-page/i18n.js): 문구와 접근성 설명의 언어 바인딩.
- [app.js](../../../landing-page/app.js): 스크롤 장면, 시간 기반 대화, 재생 제어.
- [preview.js](../../../landing-page/scripts/preview.js): 로컬 HTTP와 폰트 MIME 응답.
- [i18n.test.js](../../../landing-page/test/i18n.test.js): `npm test`로 언어 선택·문구 치환·정적 바인딩 등을 검사한다.

레이아웃과 재생 제어는 브라우저에서 별도로 확인한다. 자동 테스트 통과만으로 모바일 배치나 모션 품질을 검증했다고 해석하지 않는다. 프롬프트·캐릭터 원문·인증 값과 실제 AI 호출을 사용하지 않는다.

2026-11-07 검증에서는 자동 테스트 9개와 JavaScript 구문 검사를 통과했다. 브라우저의 1280×720·768×900·390×844·320×568 화면에서 가로 넘침 없음과 CTA·제어 버튼 배치를 확인했다. 일시정지·다시 보기·키보드 조작·반응 토글과 비교 카드의 재생 전후 높이 유지도 확인했다. 콘솔 오류·경고는 없었다.
