## 공통 작업 지시

각 단계에서 AI에게 아래 지시와 해당 단계의 요청문을 함께 제공한다.

> `AGENTS.md`와 `docs/conversation-episode-development-report.md`를 먼저 읽고 현재 단계만 구현한다. 실사용 `.env`, `prisma/dev.db`, `node_modules`, `content/`는 수정하지 않는다. 기존 호출자와 테스트를 읽고 최소 변경으로 작업한다. 격리된 임시 DB를 사용해 Prisma 변경을 검증한다. 관련 단일 테스트와 전체 `npm test`를 실행하고, 변경 파일·검증 결과·다음 단계에 남긴 의존성을 보고한다. 문서와 코드가 충돌하거나 현재 단계 밖의 정책 결정이 필요하면 추측해 구현하지 말고 중단해 질문한다.

각 단계는 앞 단계의 공개 계약을 바꿔야 할 경우 먼저 개발 계획을 수정하고 이유를 기록한다. 다음 단계 기능을 미리 구현하거나 호환성용 이중 경로를 장기간 남기지 않는다.
