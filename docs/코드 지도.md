파일을 찾을 때 사용하는 참조 문서다. 전체 흐름은 [구조와 흐름](구조와%20흐름.md), 바꾸려는 동작별 출발점과 테스트는 [개발](개발.md)에서 먼저 볼 수 있다.

## 실행과 공통 기반

| 파일 | 역할 |
| --- | --- |
