# AiMate

Discord와 CLI에서 캐릭터와 대화하는 서비스입니다. 한 프로세스에서 여러 캐릭터를 실행하고, 짧은 메시지·답장·리액션·이미지를 같은 대화 흐름으로 처리합니다.

Node.js ESM · Vercel AI SDK · discord.js · Prisma / SQLite

## 개발 시작

1. [시작하기](docs/시작하기.md): 패키지·콘텐츠·인증을 준비하고 CLI에서 첫 대화를 실행합니다.
2. [구조와 흐름](docs/구조와%20흐름.md): 메시지 하나가 저장·생성·전송되는 순서를 읽습니다.
3. [코드 지도](docs/코드%20지도.md): 실제 파일 이름과 역할을 찾습니다.
4. [개발](docs/개발.md): 바꾸려는 동작의 수정 지점과 테스트를 확인합니다.

캐릭터와 프롬프트는 Git에서 제외된 `content/`에 별도로 준비합니다. 실행 설정은 [config/default.yaml](config/default.yaml), 인증 값은 환경 변수에 둡니다.

전체 문서는 [개발 위키 홈](docs/홈.md)에서 확인할 수 있습니다. 옵시디언에서는 `docs/`를 보관함으로 열면 됩니다.
